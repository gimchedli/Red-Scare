# Red-Scare

## Utils

The utils/ directory contains utility functions that can be reused for all tasks.

It currently contains:

- <i>parser.py</i> for parsing the inputs (since all tasks and tests provide the same input format)
- <i>test_runner.py</i> for the solver function on all of the test files in data/, with formatted printing
- <i>run_all.py</i> Run this to generate the results.txt file
